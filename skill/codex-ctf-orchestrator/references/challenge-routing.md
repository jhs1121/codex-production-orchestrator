# Challenge Routing

Start with evidence, not category assumptions.

- Crypto: encodings, number relations, keys/nonces, statistical structure, known primitives.
- Reverse: file format, architecture, imports, strings, control flow, constants, dynamic behavior.
- Pwn: binary protections, interface, crash conditions, local harness, intended primitive.
- Web: supplied source/container, routes, trust boundaries, serialization, storage, exact organizer endpoint.
- Forensics: metadata, timeline, containers, filesystems, packets, memory artifacts, hidden/embedded objects.
- Data security: logs, databases, APIs, access patterns, leakage paths, integrity/lineage.
- Misc/mixed: identify the smallest test that separates competing hypotheses.

Use one triage pass, then bounded experiments. Do not launch every available tool.
