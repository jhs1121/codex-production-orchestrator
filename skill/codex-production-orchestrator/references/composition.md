# Skill Composition

Multiple Skills may be active when their responsibilities do not conflict.

For authorized CTF work:

1. CTF Skill defines `AUTH_SCOPE`, target boundaries, hypotheses, evidence, and recovery codes.
2. Production Skill sizes packages, assigns ownership, chooses leaves, and limits redundant work.
3. Every CTF leaf receives the same scope envelope.
4. If a Production rule would broaden the CTF scope, the CTF scope wins.
5. There is still exactly one primary coordinator.
